FASTQ Quality Analysis Tool
A Python-based bioinformatics tool for parsing, analyzing, and visualizing FASTQ sequencing data, including quality scores, GC content, and nucleotide frequency.

📌 Features
✅ Parse FASTQ files to extract sequence and quality scores
✅ Compute total reads, total bases, and average read length 
✅ Analyze base quality scores for accuracy assessment 
✅ Compute GC content for stability evaluation 
✅ Count occurrences of A, C, G, and T bases 
✅ Generate bar plots for nucleotide frequency visualization
